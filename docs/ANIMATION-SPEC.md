## Interaction rules

- Glass is a CSS-only treatment on existing surfaces. It adds no reveals, shimmer, lift or observers; existing hover/focus and system/site reduced-motion behaviour remain. Gate, arrival morph, carousel and masked reel geometry/behaviour are unchanged.

- Tie scroll motion to document travel and keep the browser’s normal scrolling, navigation and history.
- The arrival lazily loads a privacy-enhanced `youtube-nocookie.com` iframe only when eligible and allowed to play. Keep the poster until the API reports playing and on embed/API failure or blocked autoplay. Cover the clipped frame with a centred 16:9 iframe, with pointer events disabled. The API mutes, seeks each loop to 13 seconds and pauses/resumes for visibility, active card and entrance-door state. Route-transition clones use the poster rather than copying a cross-origin player.
- The revision-2 entrance is a labelled modal dialog. Background content is inert, focus is contained and html overflow is hidden until entry; wheel/touch defaults are never cancelled. The pre-paint gate still records `sessionStorage.tHouseIntroSeen`. Click/key/wheel during draw or spray only reveals the button; click/Enter/Space on the button enters, Escape enters without animation, and hidden-tab handling finishes immediately. There is no automatic hard cap. A six-second CSS failsafe shows the button/title statically after hydration, or clears the pending layer and scroll lock if hydration never happens. A stalled opening resets to the static invitation after three seconds. The poster is preloaded and playback starts when the door begins opening. Failure to play retains the poster, without waiting for media readiness.
- Use CSS for brief state changes and GSAP ScrollTrigger for choreographed movement. Keep animation tied to visible layers and clean up when leaving the page.
- Follow the visitor’s system preference. The site’s motion control can further reduce movement. Keep navigation available from the first view with JavaScript disabled or motion reduced; the arrival uses a poster without loading an iframe.
- The full-screen menu supports keyboard focus, Escape and returning focus to its opener. Navigation through the menu leads directly to the requested page.
- Keep carousel browsing manual. Arrows, keyboard focus and swipes browse destinations without opening a page. Escape during the outgoing card animation cancels it and returns focus to the selected card.
- On desktop pointer hover, widen a resting card to 16:9 over 300 ms. Pause the preview during turns and dragging. Use the current card size and artwork as the first frame of the flip.
- Reveal the spray underline beneath the carousel arrows on pointer hover or visible keyboard focus. Show the full mark immediately in reduced motion.
- The silent homepage background loop is decorative and has no overlaid pause or Explore control, at the owner's request. It pauses offscreen, in hidden tabs, during the entrance gate and when Watch is not active. Autoplay failure retains the poster. Tab moves from the header directly into the carousel; focus settles it before interaction. The header's Skip to content link remains available. Episode playback remains a separate, user-initiated action.
